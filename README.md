# DC_BLE_Lockin
关于直流传感器的功能代码开发

## 开发板 LED 蓝牙状态提示

P-NUCLEO-WB55 板载绿色 LED 现在专用于显示传感器侧蓝牙链路状态：

- 上电并进入等待连接/广播状态：绿色 LED 每 250 ms 翻转一次。
- HCI 蓝牙连接建立：停止闪烁，绿色 LED 常亮。
- 蓝牙连接断开：绿色 LED 立即熄灭并重新开始闪烁。

闪烁由 RTC Hardware Timer Server 的重复定时器驱动，不使用 `HAL_Delay`，不会阻塞 BLE、ADC、DAC 扫描或数据队列。原来在 ADC 回调、DAC 命令和通知开关中操作绿色 LED 的代码已移除，避免覆盖连接状态。蓝色 LED 继续用于命令/扫描活动，红色 LED 继续用于错误反馈。

调试构建产物：

- `build/Debug/BLE_Custom.elf`
- `build/Debug/BLE_Custom.hex`
- `build/Debug/BLE_Custom.bin`

## 八节点连接时序（2026-09-09）

中继支持上位机手动释放连接、30秒退避后自然重连；传感器无需接收额外的释放命令，仍在断链后自动恢复广播。扫描期间断链时，本版会恢复扫描前DAC值并终止未完成扫描，避免输出停留在扫描中间值。重连后需要重新发起扫描。

中继统一建立100 ms连接间隔、latency=0、3.2 s监控超时的链路。传感器关闭原示例的按钮触发L2CAP参数切换；即使后续重新启用该功能，候选间隔也固定为100 ms。可靠帧ACK等待时间从180 ms调整为600 ms，最多重传3次，避免在100 ms连接周期下过早重传。八台传感器都应更新固件；组网及重连验证步骤见工作区`MULTI_NODE_ARCHITECTURE.md`。
